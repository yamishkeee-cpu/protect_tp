# protect_tp
Проект технологии программирования 
1. Чат-бот для знакомств внутри университета 
2. Функционал: поиск людей в команды(учебные проекты, ивенты официальные(с кем сходить)), поиск людей для лайф общения и походов куда-нибудь. Анкеты для мероприятий можно сделать временными
3. В анкетах для людей можно указывать цель знакомства 
4. редактирование профиля, фото, описание, местонахождение, цель общения
