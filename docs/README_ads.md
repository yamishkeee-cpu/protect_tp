# Как работает реклама в боте

Описание соответствует текущему коду проекта после исправлений рекламы.

## Главное правило

Бот считает успешно отправленные анкеты в основном поиске отдельно для каждого пользователя. После очередной анкеты он проверяет, пора ли отправить рекламу. Если пора, отправляет одно объявление отдельным сообщением с пометкой «Реклама».

Пример для единственного активного объявления с частотой 3:

```text
Анкета 1 → Анкета 2 → Анкета 3 → Реклама
Анкета 4 → Анкета 5 → Анкета 6 → Реклама
```

Это происходит при просмотре анкет. Таймера, серверных тиков и фоновой рассылки здесь нет.

## Что считается анкетой

Счётчик увеличивается, когда Telegram успешно принял отправку карточки анкеты в основном поиске. Бот не может проверить, прочитал ли её человек.

В счётчик не входят:

- нажатия кнопок и переходы по меню сами по себе;
- анкеты без фото и с фото, которое Telegram отклонил;
- сообщение о том, что анкеты закончились;
- просмотр своей анкеты, уведомления о симпатиях и взаимных лайках;
- временные анкеты и события;
- просмотр рекламного объявления администратором в режиме предпросмотра.

Если нажатие «лайк» или «пропустить» приводит к успешной отправке следующей анкеты, учитывается именно эта новая отправка.

Считаются отправки, а не уникальные люди. Если после сброса истории поиска та же анкета появилась снова, её успешная отправка снова увеличит рекламный счётчик.

## Как выбирается объявление

После каждой успешно отправленной анкеты бот:

1. Увеличивает личный счётчик пользователя на 1.
2. Отбирает объявления, которые включены, подходят по датам, достигли своей частоты и ещё не исчерпали лимит показов этому пользователю.
3. Среди подходящих выбирает объявление, которое этому пользователю показывали меньше всего раз.
4. Если таких объявлений несколько, выбирает случайное.
5. Отправляет только одно объявление.
6. После успешной отправки записывает показ и обнуляет личный счётчик пользователя.

Если подходящего объявления нет, счётчик сохраняется и продолжает расти при следующих отправках анкет.

## Важный нюанс: счётчик общий для всех объявлений

У пользователя один счётчик анкет между рекламными показами. Отдельного счётчика анкет для каждого слота нет. Любое успешно отправленное объявление обнуляет этот общий счётчик.

Поэтому частота означает: **минимум сколько анкет должно пройти после последней рекламы, чтобы это объявление могло участвовать в выборе**.

### Одинаковая частота

Есть объявления А и Б, у обоих частота 3 и нет лимитов.

- После первых 3 анкет случайно выбирается А или Б: показов у обоих пока 0.
- Если первым выбрано А, после следующих 3 анкет будет выбрано Б: его показывали реже.
- Ещё через 3 анкеты число показов сравняется, и выбор снова будет случайным.

Строгой очереди по номеру или дате создания нет. Одно объявление может повториться на двух соседних рекламных местах, если в момент второго выбора число показов у кандидатов одинаково.

### Разная частота

Есть А с частотой 3 и Б с частотой 10. Оба включены, подходят по датам, у А нет лимита.

А будет доступно после каждых 3 анкет и при успешной отправке будет обнулять счётчик. До 10 счётчик не дойдёт — Б в таких условиях не покажется.

Б сможет участвовать в выборе, если А станет недоступно: например, будет выключено, закончится по дате или исчерпает лимит для этого пользователя. Если нужна ротация нескольких объявлений, в текущей реализации удобнее задавать им одинаковую частоту.

## Настройки в админ-панели

Путь: `/admin` → «📢 Реклама» → «➕ Новая реклама».

| Параметр | Как влияет на показ |
| --- | --- |
| Текст | Содержимое рекламной карточки, до 800 символов. |
| Картинка | Необязательна. Без неё отправляется текстовая карточка. |
| Ссылка | Адрес рекламодателя: HTTPS, без сокращателей. |
| Текст кнопки | Надпись на кнопке, до 30 символов. |
| Частота | От 1 до 1000 анкет; порог участия объявления в выборе по общему счётчику. |
| Лимит на пользователя | Максимальное число показов этого объявления одному человеку за всё время. 0 — без ограничения. |
| Дата начала | До этой даты объявление не участвует в выборе. Пропуск — без ограничения по дате начала. |
| Дата окончания | Последний день показа включительно. Пропуск — без ограничения по дате окончания. |
| Включение | Даже подходящее по датам объявление не показывается, пока оно выключено. |

После создания можно запустить объявление или сохранить выключенным. Включение не отправляет его всем сразу: проверка произойдёт после следующей успешно отправленной анкеты каждого пользователя.

Даты проверяются по локальной дате сервера, на котором работает бот. Отдельного выбора часового пояса для рекламы нет.

В карточке слота доступны включение/выключение, редактирование, удаление и статистика.

### Как изменить существующий слот

Откройте `/admin` → «📢 Реклама» → нужный слот → «✏️ Редактировать». Выберите параметр и отправьте новое значение. Менять можно текст, картинку, ссылку, текст кнопки, частоту, лимит и обе даты. Новое значение сохраняется сразу после корректного ввода; «Отмена» возвращает к выбору параметра без сохранения ввода.

Картинку и ограничения по датам можно удалить кнопкой «🗑 Убрать значение». Для снятия лимита показов введите 0. Дата окончания не может быть раньше даты начала: если переносите весь период, сначала измените подходящую границу или временно уберите её.

Редактирование сохраняет номер слота, статистику, накопленные показы пользователей и статус включения. Счётчик анкет также не сбрасывается. Если новый лимит уже достигнут пользователем, дальнейшие показы ему прекращаются; повышение лимита может снова разрешить показы.

Изменения учитываются при следующих проверках рекламы. Уже отправленные сообщения не переписываются. При этом кнопка старого сообщения обращается к тому же слоту: после изменения ссылки бот выдаст новый адрес. Изменение записывается в журнал действий.

## Что сохраняется между сеансами

Счётчик анкет и история рекламных показов хранятся в базе данных. При сохранении той же базы:

- перезапуск бота не сбрасывает счётчик и лимиты;
- выход в меню и повторный вход в поиск не сбрасывают счётчик;
- сброс истории просмотренных анкет не сбрасывает рекламный счётчик;
- выключение и повторное включение объявления не обнуляют его прошлые показы;
- суточного сброса лимитов нет.

Анкеты учитываются и тогда, когда нет доступной рекламы. Например, пользователь просмотрел 20 анкет без активных объявлений. Если включить объявление с частотой 10, оно может появиться после следующей анкеты: накопленный счётчик уже больше порога.

Новый слот получает собственную историю показов и новый лимит, даже если его текст совпадает с удалённым. Общий счётчик анкет пользователя при создании слота не сбрасывается.

## Выключение и удаление

- «Выключить» исключает объявление из дальнейшего выбора, сохраняя слот и его статистику.
- «Удалить слот» → подтверждение удаляет слот из базы объявлений. Он больше не выбирается для новых показов.
- Уже отправленные пользователям сообщения остаются в переписке.
- У выключенного объявления кнопка в старом сообщении продолжает выдавать ссылку. После удаления слота бот отвечает «Реклама недоступна».
- История показов и нажатий удалённого слота остаётся в базе, удаление записывается в журнал. Карточки этого слота в админке уже нет.

Если отправка уже началась до выключения или удаления, такое сообщение ещё может дойти пользователю.

## Статистика и кнопка объявления

«Показ» записывается после успешной отправки рекламного сообщения. Это не подтверждение прочтения человеком.

Кнопка на карточке сначала обращается к боту. Бот записывает нажатие и отправляет отдельное сообщение с кнопкой «🔗 Перейти», которая открывает сайт.

| Показатель | Что означает |
| --- | --- |
| Показы | Все записанные успешные отправки объявления. |
| Уникальные зрители | Количество разных пользователей с записанными показами. |
| Нажатия | Все обращения к боту через кнопку рекламной карточки, включая повторные. |
| Уникальные нажавшие | Количество разных пользователей, нажавших эту кнопку. |
| CTR | Нажатия / показы × 100%. |

Переход на внешний сайт отдельно не отслеживается. Из-за повторных нажатий CTR может быть выше 100%. Предпросмотр в админке не записывает показы и нажатия.

## Что происходит при ошибках

Если Telegram отклонил фото анкеты, бот пробует следующую анкету. Неотправленная анкета не увеличивает рекламный счётчик.

Если не удалось отправить рекламу, ошибка записывается в лог, показ не записывается, счётчик не обнуляется. После следующей успешно отправленной анкеты бот снова попробует подобрать рекламу.

Параллельные рекламные проверки одного пользователя выполняются последовательно внутри одного процесса бота. Эта защита не распространяется на несколько одновременно работающих процессов с общей базой. Отправка в Telegram и запись показа в базу также не являются единой операцией: при аварии между ними сообщение может дойти без записи в статистику.
